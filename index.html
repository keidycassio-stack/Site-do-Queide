01 · Introdução

O que é um sistema operativo?

É a primeira camada de software que faz funcionar o hardware e serve de intermediário entre este, o utilizador e as aplicações. Pode ser fechado (código-fonte privado) ou aberto (código-fonte público, que qualquer pessoa pode estudar, modificar e distribuir).

🔓

Código aberto

O código pode ser lido, auditado e melhorado pela comunidade.

⚖️

Licenças livres

GPL, BSD, MIT… definem o que se pode fazer com o software.

🌍

Comunidade global

Milhares de voluntários e empresas colaboram no desenvolvimento.

02 · História

Evolução histórica do Linux e do software livre

O Linux não nasceu do nada: assenta no Unix e no projeto GNU.

1969

Ken Thompson e Dennis Ritchie criam o Unix nos Bell Labs da AT&T.

1983–85

Richard Stallman lança o projeto GNU (1983) e funda a Free Software Foundation (1985), com o objetivo de criar um sistema operativo totalmente livre.

1991

O estudante finlandês Linus Torvalds anuncia o seu kernel “Linux”. Combinado com as ferramentas GNU, forma o sistema GNU/Linux.

1993

Nascem o Debian e o Slackware, das distribuições mais antigas ainda ativas.

1998

É fundada a Open Source Initiative e o termo “open source” ganha força junto das empresas.

2004

Lançamento do Ubuntu, que populariza o Linux no desktop.

2008

Chega o primeiro telemóvel Android, baseado no kernel Linux.

Hoje

O Linux domina servidores, cloud, supercomputadores e dispositivos embebidos.

03 · Versões e distribuições

Versão ≠ Distribuição

Versão release

Um ponto específico na evolução de um mesmo software. Ex.: kernel Linux 6.x, Ubuntu 24.04, Debian 12.

  • Numeração identifica correções e novidades
  • Pode ser LTS (suporte de longo prazo) ou estável/rolling

Distribuição distro

Um pacote completo montado em torno do kernel: ferramentas GNU, gestor de pacotes, ambiente gráfico e configurações por defeito.

  • Cada distro tem objetivo e público próprios
  • Todas partilham o mesmo kernel base

04 · Comparação

Código aberto vs código fechado

Open Source aberto

  • Gratuito ou de baixo custo
  • Código auditável e transparente
  • Altamente personalizável
  • Correções de segurança rápidas pela comunidade
  • Sem dependência de um único fornecedor

Desvantagens

  • Suporte oficial nem sempre garantido
  • Menos software comercial nativo
  • Curva de aprendizagem maior

Exemplos: Linux, FreeBSD, Android (AOSP), Chromium OS.

Código fechado proprietário

  • Suporte técnico oficial
  • Grande compatibilidade com software e hardware comerciais
  • Interface uniforme e familiar
  • Fácil para utilizadores não técnicos

Desvantagens

  • Licenças pagas
  • Código não auditável
  • Dependência do fornecedor
  • Pouca margem de personalização

Exemplos: Windows, macOS, iOS.

05 · Particularizar o Linux

Conceitos básicos e partes constituintes

Um sistema Linux é feito de camadas, cada uma com uma função clara.

Aplicações Firefox, LibreOffice…
Ambiente gráfico GNOME, KDE, XFCE
Shell bash, zsh
Bibliotecas e utilitários GNU, glibc
Kernel Linux núcleo do sistema
Hardware CPU, RAM, discos

Kernel

Gere CPU, memória, processos e dispositivos. É o “Linux” propriamente dito.

Shell

Interpretador de comandos: liga o utilizador ao kernel através do terminal.

Sistema de ficheiros

Estrutura em árvore a partir de /. Tipos comuns: ext4, XFS, Btrfs.

Gestor de pacotes e bootloader

Instala software (apt, dnf, pacman) e arranca o sistema (GRUB).

06 · Instalação e configuração

Como se instala uma distribuição

Requisitos

Verificar CPU, RAM, espaço em disco e compatibilidade de hardware.

Backup

Guardar dados importantes antes de mexer em partições.

Escolher a distro

Em função do objetivo: desktop, servidor, segurança, etc.

Modo de instalação

Máquina virtual (VirtualBox), dual boot ou instalação completa.

  1. Descarregar a ISODo site oficial da distribuição, verificando o checksum.
  2. Criar o suporte de arranquePen USB com Rufus ou balenaEtcher, ou ISO montada na VM.
  3. Arrancar pelo USBEscolher o dispositivo no menu de arranque (BIOS/UEFI).
  4. Idioma, teclado e redeSelecionar português e o layout de teclado correto.
  5. Particionar o discoMínimo: raiz / e swap; opcionalmente /home separada.
  6. Criar utilizador e palavra-passeDefinir fuso horário e nome da máquina.
  7. Concluir e reiniciarRemover o USB e arrancar pelo GRUB.

Atualizar

sudo apt update && sudo apt upgrade

Drivers e codecs

Instalar drivers gráficos e multimédia se necessário.

Segurança

Ativar firewall (ufw) e usar palavras-passe fortes.

Software

Instalar aplicações com o gestor de pacotes.

08 · Conclusão

O poder de partilhar código

Os sistemas operativos open source mostram que a colaboração aberta pode produzir software robusto, seguro e flexível. O Linux, nascido de um projeto de estudante, é hoje a base de grande parte da infraestrutura digital mundial. Conhecer o seu funcionamento e a linha de comandos é uma competência essencial para qualquer técnico de gestão e programação de sistemas informáticos.
